# PRUVA — Matriz maestra de trazabilidad (Orden 08, 2026-11-12)

Cadena por fila: **Objetivo → Requisito → Funcionalidad → Código → Prueba → Estado → Brecha → Acción pendiente → Criterio de aceptación.**

Los identificadores son estables; úsalos en las órdenes siguientes.

- `OBJ-x`: objetivos del producto.
- `REQ-xx`: requisitos.
- `F-xx`: funcionalidades (`PRUVA_FEATURE_INVENTORY.md`).
- `RSK`, `CAP` y `DT`: riesgos y deuda (`PRUVA_TECHNICAL_DEBT_AND_RISKS.md`).
- `RM-xx`: tareas del roadmap (`PRUVA_COMPLETION_ROADMAP.md`).

**Estado.**

- **OK**: implementado y probado, en local o en staging.
- **OK-rama**: probado, pero sin desplegar.
- **SIM**: probado solo con un servicio simulado.
- **PARCIAL**: falta parte de la funcionalidad.
- **AUSENTE**: no existe.
- **BLOQ**: depende de algo externo.
